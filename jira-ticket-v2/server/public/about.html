About This Dashboard

Background, purpose, audience, and technical context for the RWC-Indonesia Jira monitoring dashboard.

Purpose

This dashboard provides a centralized view of issues related to the Regional WMO Centre for Climate Monitoring and Assessment (RWC-Indonesia) tracked within the WMO Jira system.

System Overview

The RWC-Indonesia Dashboard is designed to streamline the monitoring, analysis, and reporting of tasks and issues. It pulls data directly from the WMO Jira instance to ensure real-time visibility.

Key Features

  • Issue List: A searchable and filterable table displaying all relevant issues.
  • Statistics: Visual representations (charts) showing the distribution and trends of issues by status, assignee, priority, etc.
  • Reporting: Tools to generate summaries and detailed reports on issue status and progress.
  • Data Export: Ability to export filtered issue lists to Excel or PDF formats for offline analysis or sharing.

Data Source

All data presented in this dashboard originates from the WMO Jira Instance. The dashboard fetches issues assigned to or related to the RWC-Indonesia project/category.

Technology Stack

This web application is built using standard web technologies:

  • Frontend: HTML, CSS (Bootstrap 5), JavaScript
  • Charts: Chart.js
  • Data Export: SheetJS (xlsx) for Excel, jsPDF & jsPDF-AutoTable for PDF
  • Data Fetching: JavaScript Fetch API (likely connecting to a backend API or directly to Jira if CORS allows)

Target Audience

This dashboard is intended for use by:

  • RWC-Indonesia team members
  • WMO staff coordinating with RWC-Indonesia
  • Project managers and stakeholders requiring visibility into task progress
