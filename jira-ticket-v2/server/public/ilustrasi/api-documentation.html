API Documentation

REST API endpoints available in the dashboard system

Base URL: http://localhost:3000
Public Endpoints
GET /api/issues

Get all issues from the database

Response
[{ "key": "WDQMS-1234", "summary": "...", "status": "Resolved", ... }]
GET /api/countries

Get list of countries for filtering

Response
[{ "id": 1, "name": "Thailand", "country_code": "TH" }, ...]
GET /api/logs/scrape?lines={number}

Get scrape logs with optional line limit

Query Parameters
lines: number (default: 100, max: 5000)
Admin Authentication
POST /api/admin/login

Authenticate admin user

Request Body
{ "username": "admin", "password": "password123" }
Response
{ "token": "jwt_token_here", "user": "admin" }
GET /api/admin/verify Auth Required

Verify admin token validity

POST /api/admin/logout Auth Required

Logout admin user

Country Management
GET /api/admin/countries Auth Required

Get all countries (admin)

POST /api/admin/countries Auth Required

Add a new country

Request Body
{ "name": "Thailand", "country_code": "TH" }
DELETE /api/admin/countries/{id} Auth Required

Delete a country by ID

Report Generation
POST /api/admin/monthly-report Auth Required

Generate monthly report (DOCX) and charts (PNG)

Request Body
{ "bulan": "Januari", "tahun": "2024" }
Response
Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document
(Binary DOCX file)
GET /api/admin/charts/{bulan}/{tahun} Auth Required

List available charts for a month

GET /api/admin/download-all-charts/{bulan}/{tahun} Auth Required

Download all 9 charts as ZIP file

Response
Content-Type: application/zip
(ZIP file containing 9 PNG charts)
GET /api/admin/download-chart/{bulan}/{tahun}/{type} Auth Required

Download specific chart type

Chart Types
Status, StatusHorizontal, StatusPie, StatusAllVertical, StatusAllHorizontal, 
StatusAllPie, Country, CountryStatus, Category
