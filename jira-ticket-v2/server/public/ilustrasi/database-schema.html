Database Schema

Database structure and data models used in the system

MySQL Database
Primary Database
issues
  • id INT PK Auto increment
  • issue_key VARCHAR(50) UNIQUE Jira issue key
  • summary TEXT Issue title
  • status VARCHAR(50) IDX Issue status
  • wigos_category VARCHAR(100) WIGOS category
  • created_date DATETIME IDX Creation date
  • updated_date DATETIME Last update
  • reporter VARCHAR(100) Reporter name
scrape_logs
  • id INT PK Auto increment
  • timestamp DATETIME IDX Log timestamp
  • level VARCHAR(20) Log level
  • message TEXT Log message
  • issues_count INT Issues scraped
SQLite Database
countries.db
countries
  • id INTEGER PK Auto increment
  • name TEXT Country name
  • country_code TEXT UNIQUE ISO code
admin_users
  • id INTEGER PK Auto increment
  • username TEXT UNIQUE Admin username
  • password_hash TEXT Hashed password
