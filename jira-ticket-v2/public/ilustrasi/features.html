Features Overview

Complete list of features available in the dashboard system

Public Features

Ticket List

View all Jira WMO issues with comprehensive filtering options.

  • Paginated table view
  • Search by keyword
  • Filter by status
  • Filter by country
  • Filter by date range
  • Filter by WIGOS category
Interactive Charts

Dynamic charts with real-time data visualization using Chart.js.

  • Status distribution chart
  • 3 display modes (Vertical/Horizontal/Pie)
  • Responsive design
  • Hover tooltips
  • Click interactions
Statistics Page

Comprehensive statistics and analytics dashboard.

  • Tickets by country
  • Tickets by status
  • Stacked bar charts
  • Category breakdown
  • Time-based analysis

Admin Features

Report Generation

Generate monthly reports in DOCX format automatically.

  • Select month and year
  • Auto-generate DOCX file
  • Include issue statistics
  • Country-wise breakdown
  • Template-based generation
Docxtemplater PizZip
Chart Export

Export all 9 chart types as PNG images in a ZIP file.

  • 9 chart types
  • High-quality PNG export
  • Single ZIP download
  • Server-side rendering
  • Puppeteer screenshots
Puppeteer AdmZip
Country Management

Manage country filters used in ticket filtering.

  • Add new countries
  • Delete countries
  • Country code mapping
  • Real-time sync
SQLite
System Logs

View scrape logs and system activity.

  • View latest logs
  • Configurable line count
  • Real-time refresh
  • Log level display
Authentication

Secure admin authentication system.

  • JWT token authentication
  • Secure password hashing
  • Session management
  • Auto logout
JWT bcrypt
